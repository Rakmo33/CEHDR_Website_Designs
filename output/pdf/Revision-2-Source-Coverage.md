# Source coverage and review notes - revision 2

The revised booklet has 28 pages at 5.5 x 8.5 inches. Main checklist text is 16 pt Arial. All 107 original checklist bullets are mapped below, including repeated items. The previous design is preserved separately.

## Print instructions

Use the revised Letter duplex PDF: landscape, Actual Size / 100%, double-sided, short-edge flip. Do not select another booklet or multiple-pages-per-sheet setting. Fold the nested sheets in half and staple at the fold. Print and assemble one test copy first. No bleed is required.

The existing This Is Me card remains a separate 5 x 8-inch folded insert. It is a personal-support profile, not the laminated identification card. The revised booklet restores the ID card’s full field requirements. The source calls for a separate laminated AirNow reference; this revision restores that checklist item and links the official printable guides, but does not create an additional AirNow card.
