# CEHDR Website Designs

## Folder Structure

- Root: Current CEHDR website pages and shared newsletter template.
- `projects/oc-caregiver-guide/`: Active OC Caregiver Guide webpage and Mailchimp email.
- `drafts/community-engagement/`: Community Engagement concepts and Poll Everywhere setup notes.
- `assets/`: Shared website images used by current pages.
- `archives/`: Older page concepts, campaign exports, editable packages, and generated output.
- `codex/scripts/`: Build scripts for generated design materials.
- `codex/output/`: Generated deliverables and artwork; older exports are in `codex/output/legacy/`.
- `codex/tmp/`: Temporary working files. Participant records under `codex/output/` are excluded from Git.

## Current Project

Work on the OC Caregiver Guide should remain in `projects/oc-caregiver-guide/`.
