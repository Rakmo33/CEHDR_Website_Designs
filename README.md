# CEHDR Website Designs

## Folder Structure

- `cehdr-pages/`: Current standalone CEHDR website pages.
- `lincoln-lab/`: Single-page concepts and three self-contained multi-page variants.
- `mailchimp/`: Newsletter templates and event email HTML.
- `cehdr-pages/Caregiver Resource Guides/`: OC, LA, and Inland Empire caregiver guide HTML pages.
- `cehdr-pages/community-engagement/`: Community Engagement concepts and Poll Everywhere setup notes.
- `archives/`: Older page concepts, campaign exports, editable packages, and generated output.
- `codex/scripts/`: Build scripts for generated design materials.
- `codex/output/`: Generated deliverables and artwork; older exports are in `codex/output/legacy/`.
- `codex/tmp/`: Temporary working files. Participant and event-administration records are stored outside this repository in `../Private_Event_Records/`.
